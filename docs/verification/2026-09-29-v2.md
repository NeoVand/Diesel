## Geometry and camera evidence

The browser keeps **587** purchased source groups and **88** educational component records. **569** source groups have unique, strong geometric associations to native vendor STEP product labels. Those labels do not verify Caterpillar part identity or serial applicability. The native audit recovered 589 usable meshes but found empty/unbounded pieces and meshing failures; it did not establish authentic moving internals. Original archives are preserved.

The [geometry report](verification/geometry-verification.json) sweeps 721 phase samples across all twelve educational cylinders, checking connected pins and constant rod length. The minimum authored valve-to-crown and head-to-crown clearances are 7.50 mm and 17.33 mm at the teaching scale. It also checks 24 camera fits and closed-event flow gating. These are implementation constraints, not Caterpillar manufacturing tolerances.

The [camera report](verification/camera-verification.json) applies a saved pose with pending orbit/pan/zoom inertia and checks 120 subsequent updates. Maximum pose error is approximately 3.20 × 10⁻¹⁵ display units. Fit now clears a component-only zoom while preserving the current section cylinder. Checkpoints restore sampled phase and camera along with discrete visibility and operating settings.

## Measured rendering

The [final frame sample](verification/render-benchmark.json) uses installed headless Chrome, WebGL 2 / ANGLE Metal on **Apple M4**, a 1168 × 880 CSS-pixel canvas and requested device pixel ratio 2. The renderer caps density at **1.25**, uses half-resolution AO with eight samples, and refreshes shadows once per frame. Hidden source bodies are rejected before rasterization; entirely hidden batches are skipped.

With the V12 moving and **all five flow systems enabled**, a warmed 119-interval sample measured **16.7 ms median and 16.7 ms 95th percentile**, approximately 60 FPS. Average work across render passes was 663 draw calls and 637,000 triangles. This is a short sample on the named hardware, not a universal performance guarantee or a long-duration GPU-memory test. Higher-density settings were slower and were not retained as the default.

## Live guide and audio

The actual Codex SDK/native harness ran the configured OpenAI guide through browser-scoped MCP tools. In the final live cutaway request, four actions received **applied** browser acknowledgements. The resulting view showed **cylinder 02 at local 300° compression**, equivalent to global 360°, paused with the complete cutaway fitted. The guide correctly described closed intake/exhaust valves and qualified the timing as illustrative. The browser console reported no errors.

A separate live request saved a checkpoint, selected and removed cylinder 02's piston, and restored the checkpoint. Three browser acknowledgements recorded the selection, removal and restoration; the final removed set was empty, phase remained global 360°, and the guide described the restored state. This run occurred before the final Fit correction and verified restoration of the saved component-close-up camera. It did not establish the whole-cutaway framing later verified in the final run.

Real GPT Audio 1.5 narration returned **HTTP 200, audio/wav**. Browser Resource Timing recorded **1,214,444 decoded bytes** over approximately **5.8 seconds**. The UI reached playing state and the Stop control returned it to idle. Automation's response-body helper did not expose these audio bytes, so the byte count comes from browser Resource Timing. The audio is generated explanation, not simulated engine acoustics.

Sanitized live records and canonical opening, exploded, cutaway, full-mechanism, flow, lesson, performance and mobile screenshots are saved in the chat output folder `outputs/Engine_Explorer/v2`. They contain no API keys or scene bearer tokens.

## Practical limits

The internal geometry, 350 mm rod length, representative cylinder offsets, detailed valve/injection timing, finishes and fluid paths remain educational assumptions. Fixed-1800-rpm EM1898-00 data support a nominal performance reference, not calibrated load transients, combustion, CFD, structural or acoustic predictions. Exactness requires arrangement-matched evidence and measured validation.

The current guide can operate registered scene actions and observe lesson/audio state. Starting arbitrary lessons or narration through MCP remains a later extension. Public hosting still requires purchased-asset license review, target-host native-runtime acceptance, session routing and worker isolation described in [Deployment](DEPLOYMENT.md).
